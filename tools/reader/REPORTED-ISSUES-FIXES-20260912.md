# Komga 同步与翻页反馈修复（2026-09-12）

## 行为变化

- EPUB 连续滚动启用 Readium 的 `disablePageTurnsWhileScrolling`，禁止原生横向手势切换 XHTML 资源，保留应用的纵向连续内容与目录/进度导航。
- 漫画分页、EPUB 分页设置新增独立“滑动翻页”，默认开启。关闭时保留点按与显式导航；EPUB 使用父级手势门将单指横向拖动转换为取消事件，避免 Readium 自身处理抬手翻页。连续滚动无须依靠用户开关阻止横向跳章。
- Komga 上传接口要求显式 sourceId，同时校验资源 URL 属于该连接，避免相同服务器地址的不同账号串用凭据。
- 漫画首次远端比较失败后，阅读会话内定时重试；直到比较完成仍不允许上传，继续使用现有冲突确认策略。离开章节则撤销去重标记以便再次进入时检查。
- 已确认过远端位置的 PATCH 上传失败后，交给 WorkManager 持久补传；联网执行、退避重试，按连接和书籍替换为最新任务。任务不保存凭据，使用对应连接当前请求上下文。
- 补传前重新拉取远端，页数必须一致，远端位置/完成状态必须仍等于记录的基线；有基线时间时也必须一致。远端已变化则停止旧任务写入，避免覆盖其他设备进度。连接消失或地址不匹配也不写入。此策略宁可放弃冲突补传，交给下次阅读比较处理。
- 手动标记阅读状态和恢复对应章节前取消旧任务，备份恢复期间不执行补传。队列由 WorkManager 保存，不扩展应用备份格式。首次 GET 从未成功的断网阅读不会凭空获得上传授权，保留本地位置、恢复比较后处理。
- 合并 Komga 书架初始化与偏好初次发射的重复刷新入口，避免重复强刷；保留原有统计含义。整库阅读统计仍是已有高成本路径，本次不声称完全解决反馈者的加载延迟。
